# Pokémon Road to the Champions

Versión preparada para publicar como sitio web estático.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **todo el contenido de esta carpeta** (especialmente `index.html`, `favicon.png`, `manifest.webmanifest` y `robots.txt`).
3. En **Settings → Pages**, selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda y espera a que GitHub genere la URL pública.
5. Abre la URL y comprueba que el juego carga correctamente.
6. Para aparecer en Google, añade esa URL a Google Search Console y solicita la indexación.

## Guardado

El botón **💾 GUARDAR** usa el almacenamiento local del navegador. La partida queda guardada en ese navegador/dispositivo.

Es un proyecto fan no oficial. Pokémon y sus personajes, nombres, imágenes y otros elementos relacionados pertenecen a sus respectivos propietarios.
